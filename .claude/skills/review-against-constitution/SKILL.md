# review-against-constitution

发布评审 Agent 的**共用审稿循环**。给定一份**宪法**（某一维度的偏好文档）和一篇**目标内容**，产出可复核的 finding 报表。各维度 Agent 只需说明"我用哪份宪法、审什么维度"，审稿纪律统一在这里维护。

## 输入（全部由调用方注入，本循环不假设具体文件 / 路径）
- **宪法**：调用方给出的一份偏好文档（路径或内容均可，**路径不限**——不假设它在某个固定目录）。已在上下文给出则直接用，否则用 Read 打开该路径。本循环对"哪个维度、放在哪"无知，只忠实执行拿到的这份。
- **目标**：调用方给出的文章 md / 图片 / frontmatter。已在上下文给出则直接用，否则 Read 打开传入路径（图片维度逐张打开看）。
- **确定性工具（若有）**：先跑工具拿硬事实（死链 / 体积 / 字段长度…），再在其上施加判断；工具能判的别靠主观。

## 循环
1. 读宪法，提炼该维度的原则与红线。
2. 读目标内容（图片维度逐张打开）。
3. 逐条对照，只挑**真问题**，宁缺毋滥。
4. 每个问题：定位 + 引用证据 + 指明依据宪法哪条（或标"硬伤"）。
5. 汇成报表。

## 铁律
- **不改任何文件、不改写正文 / 图**；只给方向或改写草稿，由作者亲手落盘。
- **不打分**（分数对长文不可靠、可刷、打击人）。
- 每条 finding **必须引用原文片段 / 指明具体图片**，杜绝凭空定位（防幻觉）。
- 区分「硬伤」（客观、确定性）与「依宪法的偏好建议」。
- 依据只用宪法里的话，不夹带宪法之外的个人口味；拿不准就标"建议"而非"硬伤"。

## 输出（Markdown）
先 **总览**：一句整体印象 + 最该先改的 1–2 点。
再 **finding 列表**，每条四行：
- **依据**：宪法某条（如「深入浅出—少用术语」「质量红线—承诺欠债」）或「硬伤」
- **位置 + 证据**：第几段 / 小节 / 图名 + 引用片段
- **问题**：一句话说清
- **建议**：方向或改写草稿（给"选项 + 理由"，不替作者定稿）
