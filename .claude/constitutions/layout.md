## 阅读节奏（Medium 风）
- 正文是 Source Serif Pro 衬线、~20px、行高 1.58、段落大间距——这是刻意的"Medium 式"阅读体验，审排版以此为基准。
- 段落不宜过长；长段落建议拆分以保持呼吸感。

## 结构与标题
- **`title` 是页面唯一的 h1**（主题 `single.html` 已把 frontmatter `title` 渲染为 `<h1>`）。正文**不要再出现 `# `**——否则一页多个 h1，SEO / 无障碍减分。
- **正文大章节从 `## `（h2）起**，子节 `### `（h3），**不跳级**（别 ## → ####）。
- pregate 的 `body-h1` 警告守这条，保留。
- 标题简短、能扫读。

## 符号与强调
- **加粗**用于关键术语/结论，克制，不整段加粗。
- 中文用全角标点；**中英文 / 中文与数字之间不加空格**（作者偏好，如"Agent的对抗式""3个角色"）。
- emoji 克制，正文基本不用。

## 惯用元素（沿用即可，不要劝退）
- **ASCII 流程图**用 ` ```text ` 代码块（如 `Planner <-> Evaluator -> Generator`）——这是作者偏好，鼓励。
- **对照/对比**用表格（"体验 → 规则边界"那种两栏对照）。
- **引用/外部观点**用 blockquote，并就近给出处链接。
- 代码块标语言。

## 引用与 Markdown 陷阱（踩过的坑）
- **引用规范**：机构名作平文出现，链接挂在作品 / 文章名上（"Anthropic 在 [harness-design](url) 提出…"）。
- **避免 `[^n]` 脚注**：本站 Goldmark 配置下无定义的脚注标记会原样渲染成 `[^1]`，不要用。
- **下划线 + 花括号会被原样显示**：如 `Fences_{t+1}` 会照原文渲染——改成反引号 `` `Fences_t+1` `` 或行内代码。
- **未核实 `goldmark.renderer.unsafe` 前，不要依赖行内 HTML**（行内 `<table>` / `<br>` 可能不渲染）；落地前先 `grep -i unsafe hugo.toml`。

## 表格（ananke 下无样式）
- ananke 主题对 Markdown 表格几乎无样式。改善**只动内容、不动模板 / CSS**（作者明确约束）：
  - 候选：列表化、或加一列 `vs` / `→` 作中间对照、或（确认 unsafe 后）行内样式 HTML 表。
- 不要为表格加 CSS 或改模板。

## 插图美学（重点）
作者要的是**鲜艳、简洁、信息清晰**的图例。审图时逐张打开判断：
- 一张图只讲一件事；图例/图注鲜艳、简洁，不堆信息。
- 图中文字不小于正文 ~0.8 倍，截图避免大片留白与无关 UI。
- 风格与全站一致：扁平、少装饰、强对比；流程图主色建议不超过 3 种。
- 每张图应有 alt 文本（无障碍 + SEO）；正文配图优先 webp。
- **配图放进 leaf bundle**（与 `index.md` 同目录）、用相对文件名引用——独立页面（非 leaf bundle）的兄弟图不会被发布，会裂图。
- 配图要与上下文呼应，不是凑数。
- 评审产出：对每张图给「保留 / 重做 / 调整」+ 理由（援引本节哪条）。

## 不要做
- 不替作者重排全文；只指出不符项 + 给具体调整建议。
